# MM Biryani Centre - Restaurant Website

A modern, fully responsive restaurant website for MM Biryani Centre featuring a premium black and pink design theme. Built with HTML, CSS, and vanilla JavaScript.

## 🎯 Features

### Core Functionality
- ✅ **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- ✅ **Sticky Navigation Bar** - Easy navigation with mobile hamburger menu
- ✅ **Hero Section** - Eye-catching banner with call-to-action buttons
- ✅ **Dynamic Menu System** - Filter menu by category (Biryani, Chicken, Rice, Drinks, Deals)
- ✅ **Shopping Cart** - Add/remove items, adjust quantities, persistent storage
- ✅ **Order Form** - Complete checkout with customer information
- ✅ **WhatsApp Integration** - Floating button and order confirmation via WhatsApp
- ✅ **Image Gallery** - Beautiful grid layout with hover effects
- ✅ **Customer Reviews** - Testimonial section with star ratings
- ✅ **About Section** - Business information and key features
- ✅ **Contact Section** - Location, phone, hours, and Google Maps embed
- ✅ **Social Media Links** - Footer with social links
- ✅ **Smooth Animations** - Modern transitions and hover effects
- ✅ **Form Validation** - Secure order submission with validation

## 🎨 Design Features

- **Color Scheme**: Premium Black (#1a1a1a) with Vibrant Pink (#ff1493)
- **Typography**: Modern, clean fonts for excellent readability
- **Spacing**: Consistent padding and margins throughout
- **Shadows**: Subtle shadows for depth and dimension
- **Animations**: Smooth transitions and hover effects
- **Accessibility**: Semantic HTML and proper contrast ratios
